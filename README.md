# Calculadora JS

Calculadora básica hecha con HTML, CSS y JavaScript puro, sin librerías ni frameworks.

## Funcionalidades

- Operaciones básicas: suma (`+`), resta (`-`), multiplicación (`*`) y división (`/`)
- Números decimales con el botón `.`
- **AC**: borra todo y pone la pantalla en `0`
- **DEL**: borra el último carácter
- **=**: calcula el resultado de la expresión

## Tecnologías

- **HTML5**: estructura de la calculadora
- **CSS3**: diseño con CSS Grid de 4 columnas, fondo degradado y sombras
- **JavaScript**: maneja los clics en los botones y calcula los resultados
